================================================================================
🎓 WHAT EACH FILE DOES
================================================================================

mode.py
----------------------------------------------------------------------
- Core implementation of all 3 training methods
- Handles: data loading, feature extraction, token selection, training
- Contains: Config, Trainer class, evaluation functions
- Lines: ~1100
- Purpose: Complete implementation ready to run

run_server_experiments.sh
----------------------------------------------------------------------
- Bash script for automated execution
- Checks: Python version, dependencies, GPU availability
- Options: Run all methods or just Full+Rho-1
- Creates: Output directories, saves logs, generates summary
- Purpose: One-command execution on server

EXPERIMENTAL_RESULTS.md
----------------------------------------------------------------------
- Complete documentation of all results
- Sections: Executive summary, detailed metrics, debugging, insights
- Contains: Tables, code snippets, comparisons, recommendations
- Purpose: Reference for verification and understanding results

SERVER_SETUP.md
----------------------------------------------------------------------
- Step-by-step setup instructions
- Includes: Transfer commands, installation, troubleshooting
- Hardware: Performance expectations by GPU type
- Purpose: Guide for running experiments on new server

summarize_metrics.py
----------------------------------------------------------------------
- Analyzes TensorBoard logs after experiments complete
- Outputs: Text summary with all metrics
- Extracts: Loss curves, perplexities, selection rates
- Purpose: Generate human-readable results
